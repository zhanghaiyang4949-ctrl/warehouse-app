# 查询尾号、同托盘提醒、多图与下拉刷新

用户本次重新提交的四项要求有效；此前被用户撤回的一版不单独执行。保留当前查询即时搜索、审核权限及库存/备份流程。

1. 查询端增加“只查后N位”，默认开启N=4并记住选择。开启时只按完整单号末尾N字符匹配，关闭保留原来的全字段包含搜索；支持中文英文单号，尾号模式按标准化后的单号处理。不改管理端原有找货匹配设置。
2. 管理端入库在原重复记录检查之后、写入之前，对当前托盘在库记录的规范化末4位检查。相同尾号弹窗列出已有完整单号并询问是否继续；取消保留输入与照片草稿，不增加记录。原真实重复阻止规则保留。两端按全量在库数据计算同托盘末4位冲突，使用醒目浅色底及文字提醒，不以当前筛选结果数量误判；不同完整单号用不同色区分。
3. 两端缩略图横滑并显示数量；共享无业务写入的gallery模块，点击后在该货物/托盘对应图片组内前后切换，支持手势、按钮、计数，放大缩放手势不被抢占，迟到异步响应不能覆盖当前图。撤销登录时关图库并清理图片URL。
4. 仅管理端抑制原生轻拉刷新，用始于页面顶部的180px自定义下拉手势，松手达到阈值后才刷新。保持普通滚动、图片横滑、缩放、输入及对话框滚动。未提交入库单号/备注提示确认。原生阈值不可读，180px是明确的应用阈值，不宣称精确修改Safari原阈值。真机iOS仍须用户实际确认。

建议采纳：尾号开关记忆；冲突同时有文字/完整号，避免只依赖颜色；图片数量明确显示未加载的照片仍可继续切换。

验证：尾号4/自定义N/关闭原搜索；同托盘同尾号与跨托盘/出库/删除的边界；取消入库无副作用；多图组内切换/迟到加载/授权撤销关闭；长短/横向/多指/嵌套滚动手势；原入库及查询、备份、扫码回归。
