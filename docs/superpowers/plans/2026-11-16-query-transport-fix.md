# 查询审核后登录超时修复

## 证据

- 已审核设备状态为approved，但登录请求约12秒后返回503、code20（AbortError），不是审核传播延迟。
- 腾讯云内受保护临时诊断：连接能返回响应头，但原查询文件349703字节的原始读取在10秒内不能完成；强制IPv4及JSON Accept-Encoding:gzip未解决，GitHub响应无Content-Encoding。
- 将相同私有查询内容预压缩为45333字节（减少87%），仍保存在GitHub。实际云端授权分页、缩略图、大图和撤销旧会话均通过。

## 变更边界

- 读取超时/短暂5xx只重试一次；同次读取有18秒总预算，照片校验和下载共享预算。客户端25秒等待，登录期间显示进度文案。
- 分页复用最多2分钟、最多3份内存版本，仍逐次检查当前授权；首次查询仍按5秒缓存更新，不改变永久库存存储。
- 查询同步使用本地pako2.1.0压缩组件，随包附许可证，不加载外部CDN脚本；依据服务端私有路径`.gz`启用压缩，旧JSON路径保持兼容。
- 服务识别gzip并限制解压输出20MB，继续校验version、ID和密码校验值。
- 实际私有源路径改为`query-secure/query-data.json.gz`，原JSON私有副本和主库存备份未删除、未改写。真实人员的审核状态、密码与设备凭据保持不变。
- 临时网络诊断入口部署完成前已移除。

## 验证

- 管理端/服务74项测试通过，查询端4项通过；新增首次超时重试、完整已审登录重试、分页固定版本、共享预算、浏览器真实压缩组件无损还原、压缩源读取和解压限额测试。
- 手机宽度浏览器使用假数据执行管理端原同步按钮路径，捕获到有效gzip，解压后ID和图片引用一致。
- 真实接口验收只使用临时审核设备，已清理该设备；未读取或输出人员密码，未修改真实授权和库存。
