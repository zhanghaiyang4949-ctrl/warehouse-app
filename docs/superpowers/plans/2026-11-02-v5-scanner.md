# V5 扫码集成计划

确认要求：用户最终任务 + 分堆采用单次扫码、手动确认。
稳定版本：40c9302b6139c008d5f1cc36743921ce5df81f53。
分支：feature/safari-v5-scanner；禁止推送、合并、发布。

1. 先用 Node 行为测试覆盖六入口输入、完整单号去重、配单允许重复、分堆已有内容保护。
2. 从用户 Demo 原样提取帧解码、旋转、自适应、清晰度算法；封装会话状态和启动/关闭竞态保护。统一 UI 和 single/continuous 回调。
3. 分离页面适配器。入库/快速/数据单次；批量/配单连续；两个分堆输入单次且保护未处理内容。不触发 Enter 或原按钮，快速查询是唯一自动业务调用。
4. 固定版本 ZXing 本地随包，延迟加载；失败可重试。帧始终在本机处理。
5. 模拟摄像头授权竞态、10 次开关、暂停继续、单次回调释放；浏览器移动布局和业务回归；记录实机未测项目。
6. 比较稳定提交全部旧脚本与功能，生成独立预览包和交付说明；本地提交，无部署。

UI：保留原蓝色按钮、系统字体；扫码窗口深色高清预览，控制按钮≥44px，输入字号16px避免 Safari 自动放大；仅扫码窗口新样式。
