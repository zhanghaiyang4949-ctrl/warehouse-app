# 入库小型存储额度耗尽修复

复现：真实save()写客户及托盘偏好时，localStorage抛出QuotaExceededError，在IndexedDB写入前中断；safePersistV44还会在主库提交后因辅助元数据/自动快照错误返回失败。
修复：非关键偏好和本地状态字段改为尽力保存；主库存事务失败仍阻止写入并返回失败，提交后的辅助失败不再冒充主库失败。停止重复写整库到localStorage。
空间回收：读取并验证IndexedDB主状态后，只在冗余localStorage库存镜像与主状态完整相等时释放镜像。不同版本或唯一旧库存保留；未同步记录、照片、Token、配单草稿及同步底稿均不主动删除。跨标签页版本校验保持严格。
验证：管理端106项自动测试通过。Edge手机宽度24项模拟流程通过，包括辅助写入抛Quota、真实填满localStorage、释放已核对镜像、完整入库与IndexedDB读回。主库失败测试仍返回失败。iPhone设备上需用户更新后验证。
