# 查询端人员审核与图片

用户已确认：腾讯云校验权限，库存和图片继续存 GitHub；姓名与设备首次审核，后续输入密码，管理端可撤销。不改入库、配单、出库、备份。

## 边界与迁移
- 独立普通云函数 warehouseQueryV1，仅存申请、授权和限流记录，不改原仓库云函数。
- 管理端继续使用原查询同步按钮和自动同步开关；启用受保护查询后，查询快照写入现有私有备份仓库的 query-secure/query-data.json，不再发布公共快照。云端固定配置该来源，拒绝读取公开仓库。
- 客户端只访问审核接口，不持有 GitHub Token、管理密钥、图片仓库路径。每次数据和图片请求检查授权状态；撤销后会清空界面、释放图片对象地址。
- 查询页面旧公开 query-data.json 停止读取，部署切换时删除当前公开文件；旧 Git 历史不会因此消失，需明确告知。
- 新增管理接口密钥仅留当前管理会话，不写代码、导出文件和 GitHub。首次上线需要云函数环境变量与 HTTPS 路由，先交付可测试包，不发布缺少后端的半成品。

## 实现顺序
1. 独立服务 + 持久化适配：申请、登录、状态轮询、管理员分页审核、撤销、认证读取私有快照和图片。
2. 查询端保留快速与批量匹配规则，统一结果筛选/稳定排序，适配移动端并增加缩略图与大图。
3. 管理端增加审核提醒和配置，包装原查询同步，仅改查询快照目的地，原库存备份和业务脚本不变。
4. 无真实库存的服务与浏览器回归；打包两个网页与独立云函数，记录部署步骤和实际验证范围。
