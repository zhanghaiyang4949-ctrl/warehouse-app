## 六类入口（分堆有两个实际输入框）

所有入口都由 `entries.js` 中 `targets` 和 `applyScan()` 接入共享引擎。

|入口|实际输入框|模式|成功回调与验证|
|---|---|---|---|
|入库|`inExpress`|single|填入原字符串并触发 input，关闭释放；不调用 addExpress；Node/浏览器模拟通过|
|快速找货|`findInput`|single|填入后调用原 findExpress，保留当前匹配模式；不改变库存；Node/浏览器模拟通过|
|批量找货|`batchFindInput`|continuous|按完整单号检查当前输入，逐行追加，保留先后顺序；不查询；Node/浏览器模拟通过|
|配单|`packOrdersV83`|continuous|逐行追加，保留重复，原 input/计数函数更新数量；不创建或提交任务；Node/浏览器模拟通过|
|分堆|`blindSortInputW99`、`tableSortInputW99`|single|按用户最终选择，单次填入、关闭，手动确认原分堆按钮；有未处理内容时拒绝覆盖；Node/浏览器模拟通过|
|数据整理|`dataSearchInput`|single|仅填入，不自动搜索或执行修改；Node/浏览器模拟通过|

重复处理：共享引擎3秒防连续误识别；批量找货整批去重。配单和分堆不启用整批去重，沿用原业务规则。所有单号保持字符串，不丢前导零、不自动截断、不强制数字或长度。EAN-13 使用标准校验位；修正 Demo 中枚举为数字时未应用格式校验的问题。

## 安全预览

1. **先测独立页**：将预览包中 `scanner-preview.html` 和整个 `assets/` 目录放在一个独立的 HTTPS 测试站点，Safari 访问 `…/scanner-preview.html`。可复用原 Demo 的测试托管位置。该页面不访问真实库存、IndexedDB 或 GitHub。
2. 点击扫码立即启动摄像头；首次使用时仍须允许浏览器的相机权限。连续模式会保持窗口，单次模式自动关闭。分堆测试框需清空表示确认上一件。
3. 完整仓库预览：电脑可在项目目录运行 `node tests/preview.cjs`，访问 `http://127.0.0.1:8875`。本地文件也可预览布局。手机访问电脑普通 HTTP 地址通常不能使用摄像头；手机摄像头测试须 HTTPS。
4. 完整仓库若放到测试网站，务必使用独立浏览器配置/临时浏览，避免读写正式浏览器里的本机库存。相同 github.io 域名下不同路径仍可能共享存储，不能把不同目录当作数据隔离。
5. 不要只替换 index.html：现在需要同时提供 `assets/scanner/` 目录，才能加载扫码模块。
